导航 Project
与AI紧密协作完成以下任务，导航方向，要求三天实现一个可用的最小集合:
1、构建一个仿真环境中可交互的机器人Agent
2、构建一个html网页进行可视化呈现
3、交付网页链接和github仓库地址

导航方向，具体要求如下：
1、在机器人仿真器如Isaac Lab、Habitat中搭建一个基本场景（尽量复用MP3D中的场景），一个轮式双臂机器人在一个居家房间中
2、构建一个具身Agent，可以接受语音或文字输入。用户输入“请到沙发旁边”，具身Agent根据命令规划行动，调用仿真器中的机器人导航到沙发旁边。任务完成后，具身Agent询问用户“还需要什么”
3、支持多个导航地点，用户可以指定导航到沙发、床等多个地点
注意：应仿照真实场景，只能从仿真器获取视觉信息和机器人本体状态，不应使用其他特权信息
